# ruPet creation prompt

Use in a chat with `hatch-pet` and `imagegen` available. The optional `$rupet` skill supplies tool-routing and repair guidance; it is not required to display an existing pet.

```text
Use hatch-pet to create and install ruPet as a custom desktop v2 pet. If the rupet skill is installed, use its creation workflow and relevant available Ruflo tools for recall and coordination.

Create a friendly futuristic robot with a rounded matte charcoal body, expressive cyan eye panels, purple accents, short articulated limbs, and a small lowercase “ru” chest emblem. Preserve that exact emblem: no other text, captions, labels, or guide marks. Keep eye luminosity inside the face, with no detached glow. The final artwork must have genuine transparency.

Make the robot curious, playful, and focused. Use distinct idle/blink, wave, jump, deflated failure, expectant waiting, active processing, and thoughtful review gestures. Directional movement needs a visible stride/recovery rhythm. Generate left and right separately when mirroring would reverse the emblem.

For looking around, anchor the torso and feet and turn/tilt the head. Establish clear up/right/down/left anchors, then coherent intermediate poses with both horizontal and vertical gaze cues and gradual boundary transitions.

Use the full hatch-pet validation pipeline. Relevant memory may inform repairs but cannot approve an image. Keep blind direction reviewers isolated. Install only after visual and deterministic checks pass, verify the installed package, and save a shareable ZIP and preview. Report installation separately from selection in the app. Do not publish or start recurring work unless I request it.
```
